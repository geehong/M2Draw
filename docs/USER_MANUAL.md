## 1. 화면 구성 및 워크스페이스

M2Draw의 작업 화면은 크게 5개 영역으로 구성됩니다.

| 영역 | 위치 | 주요 역할 |
| :--- | :--- | :--- |
| **상단 컨텍스트 옵션바 (`CToolOptionBar`)** | 상단 | 현재 선택된 도구나 오브젝트에 맞춰 좌표(`X, Y, W, H`), 도형 파라미터(모서리 반경, 별 꼭짓점, 원호 각도 등), 정렬/배분 버튼, **HTML UI 컴포넌트 생성 버튼**을 표시합니다. |
| **좌측 도구상자 (`CToolBoxPane`)** | 좌측 | 선택(`V`), 손(`H`), 프레임(`F`), 펜(`P`), 직선(`L`), 사각형/삼각형(`M`), 타원(`E`), 다각형/별/기어/나선/하트(`G`), 텍스트(`T`), 페인트 통(`K`), 그라디언트(`D`), 돋보기(`Z`/`X`) 및 그룹/순서/불리언/마스크 동작 버튼을 제공합니다. 우하단에 작은 삼각형 표시가 있는 버튼을 **길게 누르면 플라이아웃 서브도구 메뉴**가 열립니다. |
| **중앙 캔버스 뷰 (`CM2DrawView`)** | 중앙 | Direct2D 하드웨어 가속 벡터 캔버스, 상단/좌측 눈금자(Ruler), 격자(Grid), 스마트 가이드, 실시간 변형 기즈모를 렌더링합니다. |
| **우측 속성 패널 (`CD2DPropertyView`)** | 우측 상단 | 선택 객체의 위치/크기, 채우기(단색/선형·방사형 그라디언트), 선(두께·대시·끝모양), 공통 외형(Appearance: 바깥/안쪽 그림자, 불투명도, 블렌드 모드), 프레임 레이아웃, 표 편집, HTML 시맨틱/UI 컴포넌트 전용 속성을 편집합니다. |
| **레이어 패널 (`CLayerWnd`) & 출력창 (`COutputWnd`)** | 우측 하단 / 하단 | 레이어 및 내부 도형 계층 트리를 관리(순서 드래그, 눈 아이콘 가시성, 자물쇠 잠금)하고, 하단 출력창에서 작업 로그를 확인합니다. |

## 2. 캔버스 탐색 및 스냅 시스템

### 캔버스 이동 및 확대/축소
- **임시 손 도구 (패닝)**: 어느 도구에서든 `Space` 키를 누르고 있는 동안 마우스를 드래그하면 캔버스를 이동합니다.
- **마우스 휠 줌**: 마우스 커서 위치를 기준으로 확대/축소합니다.
- **돋보기 도구 (`Z` / `X`)**: 클릭한 지점을 중심으로 확대(`Z`) 또는 축소(`X`)합니다.

### 오브젝트 스냅 & 스마트 가이드
- **그리드 & 오브젝트 스냅 (`SnapManager`)**: 도형 생성 및 드래그 시 격자점(Grid), 정점(Endpoint), 선분 중점(Midpoint), 도형 중심(Center), 선분 위(Edge), 두 도형의 교차점(Intersection)에 정밀 스냅됩니다.
  - 드래그 중에는 **선택된 자기 자신**과 **잠긴 노드**를 스냅 대상에서 자동 제외합니다.
- **스마트 가이드 (`SmartGuides`)**: 도형을 이동하거나 크기를 조절할 때 부모 프레임 및 이웃 도형의 왼쪽/가운데/오른쪽·위/가운데/아래 정렬선을 붉은 가이드선으로 표시하고, 3개 이상의 도형 사이 간격이 같아지면 **동일 간격(Equal Spacing) 치수 배지**를 표시합니다.
  - 드래그 중 **`Alt` 키**를 누르고 있으면 스냅과 스마트 가이드를 일시적으로 해제하여 자유롭게 배치할 수 있습니다.

## 3. 벡터 도형 및 드로잉 도구

모든 기본 도형 도구는 **드래그 방식**(누른 채 끌어서 놓기)과 **2-클릭 방식**(시작점 클릭 → 이동 → 끝점 클릭)을 모두 지원합니다.
- 드래그 중 **`Shift` 키**: 정사각형 / 정원 / 수평·수직·$45^\circ$ 직선으로 비율 구속
- 상단 옵션바 **`중심부터 그리기`**: 클릭 지점을 모서리가 아닌 도형의 중심점으로 사용하여 바깥쪽으로 확장

### 기본 및 파라메트릭 도형
1. **직선 도구 (`L`)**: 두 점을 잇는 선분 패스를 생성합니다.
2. **사각형 도구 (`M`)**: 직각 또는 둥근 모서리(`Rx`, `Ry`) 사각형을 생성합니다. 생성 후 `SelectTool`로 가로/세로 비율을 다르게 늘려도 **모서리 원호 반경이 찌그러지지 않고 보존**됩니다.
3. **타원 도구 (`E`)**: 4개의 부드러운 베지어 정점으로 구성된 타원/원을 생성합니다.
4. **삼각형 도구** (사각형 버튼 길게 누르기): 이등변/정삼각형을 생성합니다.
5. **정다각형 (`G`) & 열린 폴리라인**: 변의 개수(`3~32`)를 지정하는 정다각형 및 클릭으로 꺾은선을 이어 그리는 폴리라인을 생성합니다.
6. **별 (`Star`) / 기어 (`Gear`) / 스파이럴 (`Spiral`) / 하트 (`Heart`)** (다각형 버튼 길게 누르기):
   - **별**: 꼭짓점 수(`3~32`), 내경 비율(`0.05~0.95`) 조절
   - **기어**: 톱니 수(`4~48`), 톱니 깊이 비율, 중앙 축 구멍(Bore Hole) 내경 비율 조절
   - **스파이럴**: 회전 바퀴 수(`0.5~10`) 조절
7. **원호 / 파이 / 현 / 도넛 아크 (`Arc`)**:
   - 시작 각도(`startAngle`), 스윕 각도(`sweepAngle`), 내경 비율(`innerRatio`) 및 4가지 모드(**열린 원호 `Open`**, **부채꼴 `Pie`**, **현 `Chord`**, **도넛 섹터 `Donut`**)를 지원합니다.
8. **블록 화살표 (`BlockArrow`) & 말풍선 (`Callout`)**:
   - 화살촉 길이/몸통 두께 비율을 갖는 블록 화살표와 둥근 모서리 + 꼬리(`tailPosRatio`, `tailWidthRatio`, `tailHeightRatio`)를 갖는 말풍선을 생성합니다.

### 자유 곡선 및 영역 채우기
- **펜 도구 (`P`)**:
  - 클릭하면 직선 앵커(`Corner`)가 추가되고, 클릭 후 드래그하면 대칭 곡선 핸들(`Symmetric`)이 뽑혀 나옵니다.
  - 핸들 드래그 중 **`Alt` 키**를 누르면 반대편 핸들과의 대칭 구속을 깨고 현재 핸들만 각지게 꺾습니다.
  - 시작 앵커 위를 다시 클릭하면 폐곡선(`Closed Path`)으로 닫히며, `Enter` / 더블클릭 / 우클릭으로 열린 패스를 완성합니다.
- **페인트 통 도구 (`K`)**:
  - 여러 선이나 도형이 교차해 만든 닫힌 빈 영역을 클릭하면 경계를 자동 추적하여 현재 채우기 스타일이 적용된 새 벡터 영역(`PathNode`)을 만들어 채웁니다.

## 4. 선택 도구 및 양방향 변형(Transform) 기즈모

선택 도구(`V`)로 도형을 선택하면 바운딩 박스와 함께 직관적인 **Direct2D 양방향 변형 기즈모**가 표시됩니다.

### ① 크기 조절 (Scale) & 회전각 연동 커서
- 4개 모서리(`TL, TR, BR, BL`) 및 4개 변 중앙(`T, R, B, L`) 핸들 위에 마우스를 올리거나 드래그하면, **도형의 월드 회전 각도($\theta$)에 맞춰 회전된 파란색 양방향 화살표 기즈모**가 핸들 바깥쪽에 표시됩니다.
- 마우스 커서 역시 도형이 회전된 각도를 계산하여 실제 늘어나는 방향(`↔`, `↕`, `↖↘`, `↗↙`)으로 자동 전환됩니다.

### ② 회전 (Rotate) — 상단 회전 봉 & 4모서리 바깥 근접 회전
- 상단 중앙의 원형 회전 핸들을 드래그하거나, **4개 모서리 핸들 바깥쪽 근접 구역($8\sim 18\text{px}$)** 에서 드래그하면 즉시 중심 기준점($\oplus$)을 기준으로 회전합니다.
- 회전 중 하단 HUD 알약 배지에 현재 회전 각도(`45.0°`)가 실시간으로 표시됩니다.

### ③ 면 기울이기 / 전단 변형 (Shear / Skew)
- **`Ctrl` 키**를 누른 상태에서 상/하(`T, B`) 또는 좌/우(`L, R`) 변 중앙 핸들에 마우스를 올리면 기즈모가 **변과 평행한 양방향 전단 화살표(`⇄`, `⇅`)** 로 바뀝니다.
- 그대로 드래그하면 반대편 변을 고정한 채 단일 도형 또는 다중 선택 도형 전체가 부드럽게 기울어지며(Shear), 하단 HUD 배지에 전단 각도(`Skew 15.0°`)가 실시간으로 표시됩니다.

### ④ 키보드 정밀 이동(Nudge) 및 대칭 반전
- **화살표 키 (`←`, `→`, `↑`, `↓`)**: 선택된 도형을 `1px`씩 미세 이동합니다 (`Shift + 화살표 키`는 `10px`씩 이동). 연속으로 누른 뒤 키를 뗄 때 1건의 Undo로 깔끔하게 기록됩니다.
- **대칭 반전 & $90^\circ$ 회전**: 상단 메뉴 `오브젝트 → 변형`에서 **좌우 반전(Flip Horizontal)**, **상하 반전(Flip Vertical)**, **시계/반시계 방향 $90^\circ$ 회전**을 실행할 수 있습니다.

## 5. 패스 편집 · 불리언(패스파인더) · 클리핑 마스크

### 베지어 노드(정점/핸들) 편집
- 선택된 `PathNode`의 정점(흰색 사각형)이나 곡선 핸들(파란색 원)을 직접 드래그하여 곡선 형태를 수정할 수 있습니다.
- 핸들 드래그 중 **`Alt` 키**를 누르면 양쪽 핸들의 각도 연동이 풀려 독립적으로 꺾입니다.

### 불리언 연산 (패스파인더)
2개 이상의 패스 도형을 선택한 상태에서 좌측 도구상자의 **불리언 플라이아웃** 또는 단축키로 실행합니다:
- **합치기 (`Union`, `Ctrl+Shift+U`)**: 선택된 도형들을 하나의 외곽선으로 합칩니다.
- **빼기 (`Subtract`, `Ctrl+Shift+S`)**: 맨 아래 도형에서 위쪽 도형들이 겹친 영역을 도려냅니다.
- **교차 (`Intersect`, `Ctrl+Shift+I`)**: 모든 선택 도형이 공통으로 겹치는 영역만 남깁니다.
- **제외 (`Exclude`, `Ctrl+Shift+X`)**: 홀수 번 겹친 영역은 남기고 짝수 번 겹친 영역에 구멍을 뚫습니다.
- **트림 / 분할 (`Trim`, `Ctrl+Shift+T`)**: 위쪽 도형이 아래쪽 도형을 덮는 부분을 잘라내어 겹침 없는 조각들로 분할합니다.

### 클리핑 마스크 (`Clip Mask`)
- 2개 이상의 노드를 선택하고 **`Ctrl+7`**(또는 도구상자 클리핑 마스크 만들기)을 누르면, **선택 중 가장 위에 있는 도형(최상단 Z-order)** 이 마스크 외곽선이 되어 아래쪽 도형들을 클리핑하는 마스크 그룹을 생성합니다.
- 해제는 **`Ctrl+Alt+7`** 입니다.

## 6. 프레임(Artboard) · 자동 레이아웃 · 제약 조건

### 프레임 도구 (`F`) 및 프레임으로 감싸기
- 좌측 도구상자에서 **프레임 도구(`F`)** 로 드래그하여 새 프레임(아트보드/컨테이너)을 만들거나, 기존 도형들을 선택한 뒤 `프레임으로 감싸기(Wrap in Frame)`로 묶을 수 있습니다.
- 도형을 드래그하여 프레임 안으로 놓으면 자동으로 해당 프레임의 자식으로 편입되며, 프레임 밖으로 끌어내면 레이어 직속으로 분리됩니다.

### 자동 레이아웃 (Auto-Layout: CSS Flexbox 대응)
프레임을 선택하고 우측 속성창의 **Frame / Layout** 섹션에서 설정합니다:
- **배치 모드**: `자유 배치(None)` / `가로 정렬(Row)` / `세로 정렬(Column)`
- **주축 정렬 (`Main Align`)**: `시작(Start)` / `가운데(Center)` / `끝(End)` / `양끝 균등(SpaceBetween)`
- **교차축 정렬 (`Cross Align`)**: `시작(Start)` / `가운데(Center)` / `끝(End)`
- **간격(`Gap`) 및 안쪽 여백(`Padding`)**: 자식 간 간격 및 상/우/하/좌 4방향 여백 설정
- **크기 모드 (`Sizing`)**: `고정(Fixed)` / `내용에 맞춤(Hug Contents)` / `부모 채움(Fill Container)`
- **4모서리 개별 반경 & 4변 개별 테두리**: `TL, TR, BR, BL` 반경을 각각 다르게 주거나 특정 변(`Top/Right/Bottom/Left`)에만 테두리를 그릴 수 있습니다.

### 자유 배치 제약 조건 (Constraints)
자유 배치(`None`) 프레임 안의 자식 도형을 선택하면 부모 프레임의 크기가 변할 때의 동작을 지정할 수 있습니다:
- **가로 제약**: `왼쪽 고정(Left)`, `오른쪽 고정(Right)`, `가운데(Center)`, `양쪽 늘이기(Left+Right)`
- **세로 제약**: `위 고정(Top)`, `아래 고정(Bottom)`, `가운데(Center)`, `위아래 늘이기(Top+Bottom)`

## 7. 표준 HTML UI 컴포넌트 & 인터랙티브 테이블

상단 컨텍스트 옵션바(선택 도구 활성 시 오른쪽 영역)에서 **웹/UI 컴포넌트 버튼**을 클릭한 뒤 캔버스에 클릭 또는 드래그하여 배치합니다.

> **핵심 특징**: 모든 UI 컴포넌트는 내부 도형들이 흩어지지 않는 **단일 원자 오브젝트(Atomic Object)** 로 선택·이동·리사이즈되며, HTML 내보내기 시 **절대로 이미지나 `<svg>`로 래스터화되지 않고 순수 시맨틱 HTML5 태그와 CSS로 변환**됩니다.

| 컴포넌트 | 캔버스 표시 및 주요 전용 속성 (우측 속성창) | HTML5 내보내기 결과 |
| :--- | :--- | :--- |
| **텍스트 박스 (`TextBox`)** | 태그 프리셋(`본문 p`, `제목 1~3 h1~h3`, `인용구 blockquote`, `작은 글씨 small`), 문구, 정렬(`좌/중/우`), 글자 크기, 줄간격, 굵게 | `<p>`, `<h1>~<h3>`, `<blockquote>`, `<small>` |
| **입력창 (`Input`)** | 종류(`일반 text`, `비밀번호 password`, `이메일 email`, `숫자 number`, `검색 search`, `날짜 date`, `여러 줄 textarea`), 안내 문구(`placeholder`), 입력값(`value`), 비활성(`disabled`) | `<input type="..." placeholder="..." value="...">` 또는 `<textarea>` |
| **체크 / 스위치 (`Check`)** | 종류(`체크박스`, `라디오`, `토글 스위치`), 선택 상태(`checked`), 라벨 문구, 강조 색(`accent-color`) | `<label><input type="checkbox\|radio" role="switch"><span>라벨</span></label>` |
| **콤보 / 리스트박스 (`Combo`)** | 표시 방식(**`드롭다운 (콤보)`** / **`리스트박스 (다중 행)`**), 옵션 목록(`\|`로 구분), 선택 번호(`selected`), 안내 문구, 표시 행 수(`rows`), 다중 선택(`multiple`) | `<select><option>...</option></select>` 또는 `<select size="N" multiple>` |
| **목록 (`List`)** | 종류(`글머리 ul`, `번호 ol`, `상자 목록`), 마커 모양(`원/빈 원/사각/숫자/알파벳/로마자`), 항목 목록(`\|` 구분), 항목 간격, 글자 크기 | `<ul><li>...</li></ul>` 또는 `<ol><li>...</li></ol>` |
| **바 (`Bar`)** | 종류(`진행률 progress`, `슬라이더 range`, `구분선 hr`), 현재 값/최소/최대, 값 표시 여부, 트랙·채움 색, 두께 | `<progress>`, `<input type="range">`, `<hr>` |
| **탭 (`Tabs`)** | 탭 이름 목록(`\|` 구분), 활성 탭 번호, 강조 색 | `<div role="tablist"><button role="tab">...</button></div>` |
| **배지 (`Badge`)** | 문구, 배경/강조 색, 닫기(`×`) 표시 여부 | `<span>문구</span>` |
| **카드 (`Card`)** | 상단 이미지 영역 높이, 카드 제목, 본문 내용, 하단 버튼 문구 | `<article><div>...</div><h3>...</h3><p>...</p><button>...</button></article>` |
| **페이지 번호 (`Pager`)** | 종류(`페이지 번호 pagination` / `경로 breadcrumb`), 항목 목록(`\|` 구분), 현재 위치 | `<nav aria-label="pagination\|breadcrumb">...</nav>` |
| **표 (`Table`)** | 행/열 추가·삭제, **셀 범위 병합(`Merge`) / 분할(`Split`)**, 머리글 행 수(`Header Rows`), 셀 정렬, 테두리 두께·종류(`실선/파선/점선`)·색상, 셀 여백. **셀 더블클릭 시 즉시 텍스트 입력**, 행/열 경계선 드래그로 너비/높이 조절 | `<table><thead><tr><th>...</th></tr></thead><tbody><tr><td colspan="..." rowspan="...">...</td></tr></tbody></table>` |

## 8. 우측 속성창 (채우기 · 그라디언트 · 선 · 그림자 · 외형)

1. **Position & Size (`X, Y, W, H, 회전각`)**: 선택된 노드의 정확한 수치 입력 및 변형
2. **Fill (채우기)**:
   - `없음(None)` / `단색(Solid)`(HSV 컬러 휠, RGB/HEX 입력, 16색 팔레트, 투명도) / `선형 그라디언트(Linear)` / `방사형 그라디언트(Radial)`
   - **그라디언트 도구(`D`) 연동**: 캔버스 위에서 직접 드래그해 그라디언트 시작점·끝점·초점·반지름을 지정하고, 축 위를 클릭해 컬러 스톱 추가, `Alt+클릭`으로 컬러 스톱 삭제 가능
3. **Stroke (선)**:
   - 선 두께(`Width`), 선 색상 및 투명도, 대시 패턴(`실선`, `파선`, `점선`), 선 끝 모양(`Butt`, `Round`, `Square`), 모서리 이음(`Miter`, `Round`, `Bevel`)
4. **Appearance (공통 외형 & 그림자)**:
   - **그림자 (`Shadow`)**: 사용 체크, **안쪽 그림자(`Inset`)** 토글, 오프셋 `X / Y`, 흐림(`Blur`), 확산(`Spread`, 음수 입력 시 그림자 축소), 프리셋 6종 및 16색 팔레트 + 알파(`%`)
   - **불투명도 (`Opacity`) & 혼합 모드 (`Blend Mode`)**: `Normal`, `Multiply`, `Screen`, `Overlay`

## 9. 레이어 패널 & 그룹 격리 편집(Isolation Mode)

### 레이어 패널 (`CLayerWnd`)
- 레이어 추가(`+`), 삭제(`-`), 위/아래 순서 이동 및 마우스 드래그 앤 드롭을 통한 노드 계층/순서 변경을 지원합니다.
- 각 레이어 및 개별 도형의 **가시성(눈 아이콘)** 과 **잠금(자물쇠 아이콘)** 을 즉시 토글할 수 있습니다.
- 원자적 컴포넌트(`버튼`, `표준 UI 컴포넌트`)는 내부 부속 도형이 실수로 분리되지 않도록 트리에서 단일 항목으로 깔끔하게 표시됩니다.

### 그룹 격리 편집 (Isolation Mode)
- 일반 그룹(`GroupNode`)을 **더블클릭**하면 해당 그룹 내부로 진입하여 그룹을 해제하지 않고도 안쪽 도형들을 개별 선택·이동·편집할 수 있습니다.
- 격리 편집 중에는 화면 상단에 경로 배지가 표시되고 외부 도형들은 반투명하게 잠기며, 빈 공간을 더블클릭하거나 **`Esc` 키**를 누르면 상위 단계로 빠져나옵니다.

## 10. SVG 무손실 저장 · 시맨틱 HTML5/CSS · 이미지 내보내기

1. **SVG 저장 및 열기 (`Ctrl+S`, `Ctrl+O`)**:
   - 기본 저장 모드는 표준 SVG 뷰어/브라우저와 호환되면서도 M2Draw의 모든 고급 속성(파라메트릭 도형, 프레임 자동 레이아웃, 표 병합, UI 컴포넌트 속성, 그림자)을 `m2:*` 속성으로 무손실 보존합니다.
   - 외부 배포용 **Clean SVG 내보내기**를 선택하면 `m2:*` 확장 속성 없이 순수 표준 SVG 태그만 출력합니다.
2. **시맨틱 HTML5 / CSS 내보내기 & 미리보기**:
   - 단일 `.html` 파일(내부 `<style>`) 또는 `.html` + 외부 `style.css` 분리 방식으로 내보낼 수 있으며, 즉시 웹 브라우저에서 결과를 미리볼 수 있습니다.
3. **래스터 이미지 내보내기 (`PNG`, `JPEG`, `BMP`, `WebP`)**:
   - 원하는 배율(1x, 2x 등)과 투명 배경 옵션을 지정해 고해상도 비트맵으로 내보냅니다.
