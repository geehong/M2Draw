# M2Draw 상단 도구 옵션바 및 신규 추가 도형 상세 구현 계획 (개정판)

본 문서는 **상단 도구 옵션바(ToolOptionBar)**, **사이드 툴박스 플라이아웃 서브도구**, **신규 도형(삼각형, 별, 기어, 스파이럴, 하트 등)** 의 UI 명세, 파라미터 모델, 단위 연동, 기하 수식, 구현 단계를 정의합니다.
문서 변경 경로·Undo/Redo·ShapeId 등 공통 원칙은 [Object_Architecture_and_Future_Plans.md](Object_Architecture_and_Future_Plans.md)를 따릅니다.

> 개정 사항: 파라메트릭 도형 모델 추가, 스파이럴/기어/하트 수식 정정, 명령 기반 편집 규칙, 입력 검증, 플라이아웃 규칙, 구현 단계 및 테스트 항목 추가.

---

## 1. 개요 및 설계 원칙

### 1.1 확정된 결정 사항

1. **상단 도구 옵션바**: 선택된 도구 또는 선택된 도형 종류에 따라 입력 컨트롤을 동적으로 전환합니다.
   - **`{도형} 만들기` 모드**: 도형 도구가 활성이고 캔버스에 선택된 도형이 없을 때. 값은 *다음 생성 시의 기본값*이며 드래그 생성에도 반영됩니다.
   - **`{도형} 수정` 모드**: 캔버스에서 파라메트릭 도형을 선택했을 때. 실제 파라미터를 표시하고 변경 시 즉시 반영합니다.
   - **`선택 모드`**: 일반 패스, 다중 선택, 파라미터 정보가 없는 도형에는 X/Y/W/H/회전만 표시합니다.
2. **플라이아웃 서브도구**: 우하단 삼각 표시가 있는 버튼에서 누른 채 드래그 후 놓아 선택합니다. (3장 참조)
3. **단위 연동**: 옵션바의 모든 수치는 활성 단위(`px`, `mm`, `cm`, `in`)로 표시하고, 우측 "오브젝트 설정" 패널의 Transform(X, Y, W, H)과 양방향 동기화합니다.

### 1.2 편집 원칙 (필수)

- 옵션바와 패널은 도형을 **직접 수정하지 않고 문서 명령(Command)** 으로 변경합니다. (아키텍처 문서 9.5)
- **Undo 단위**: 입력 필드 포커스 진입 시 이전 상태를 저장하고, **Enter / 포커스 이탈 / 스핀 조작 종료** 시 1개의 `ChangeShapeParamsCommand`를 생성합니다. 타이핑 중 키 입력마다 명령을 만들지 않습니다. 입력 중에는 Preview만 갱신합니다.
- **취소**: `Esc`는 입력 이전 값으로 복원합니다.
- **대상 식별**: 선택은 인덱스가 아니라 `ShapeId`로 참조합니다. (ShapeId 도입 전에는 임시로 인덱스를 쓰되, 어댑터 계층 안에 가둡니다.)
- **동기화 루프 방지**: 옵션바·패널은 문서 옵저버를 구독하여 갱신하고, 컨트롤 갱신 중에는 `m_bUpdating` 가드로 변경 이벤트를 무시합니다.
- **단위 정밀도**: 내부 값은 항상 문서 기준 단위(px)로 저장합니다. 표시 단위 전환 시 반올림된 표시값을 다시 적용하지 않으며, 값이 실제로 편집된 경우에만 내부 값을 갱신합니다.

## 2. 파라메트릭 도형 모델 (신규 핵심 설계)

현재 `PathShape`는 `SubPath/BezierNode`만 보유하므로, 선택된 도형이 별인지 기어인지, 꼭짓점 수가 몇인지 복원할 수 없습니다. 수정 모드를 위해 다음을 추가합니다.

### 2.1 데이터 구조

```cpp
enum class ShapeKind { Path, Rect, Triangle, Ellipse, Polygon, Star, Gear, Spiral, Heart };

struct RectParams     { float rx, ry; };                       // 모서리 반경 (로컬 단위)
struct TriangleParams { bool equilateral; };
struct EllipseParams  { };                                     // 크기는 바운딩 박스로 표현
struct PolygonParams  { int sides; };                          // 3~32
struct StarParams     { int points; float innerRatio; };       // 3~32, 0.05~0.95 (r_inner / r_outer)
struct GearParams     { int teeth; float depthRatio; float boreRatio; float toothWidthRatio; };
struct SpiralParams   { float turns; float innerRatio; };      // 아르키메데스 나선
struct HeartParams    { };

using ShapeParams = std::variant<std::monostate, RectParams, TriangleParams, EllipseParams,
                                 PolygonParams, StarParams, GearParams, SpiralParams, HeartParams>;
```

`PathShape`에 `ShapeKind m_kind = ShapeKind::Path;` 와 `ShapeParams m_params;` 를 추가합니다.

### 2.2 좌표 규칙

- 모든 파라메트릭 도형은 **단위 바운딩 박스(0..1)** 또는 **로컬 박스 `[0,0,W,H]`** 기준으로 `SubPath`를 생성하고, 위치/크기/회전은 `m_xf`로 표현합니다.
- 옵션바의 W/H 변경은 `m_xf`의 스케일을 바꾸는 것이 아니라 **로컬 기하를 재생성**하여 스트로크 두께가 왜곡되지 않게 합니다. 회전은 `m_xf`에 유지합니다.
- 기준점 정의 (모든 도형 공통):
  - **X, Y** = 회전 전 로컬 박스의 좌상단 (월드 좌표, 도형 중심 기준 회전).
  - 타원/다각형/별/기어/스파이럴은 보조 표기로 `Cx, Cy`(= 박스 중심)를 병기할 수 있으나 내부 값은 동일합니다.
- 일반 선택 모드에서 회전된 도형의 AABB W/H를 편집할 때는 **AABB 중심 고정**으로 스케일합니다.

### 2.3 파라메트릭 연결 해제 정책

- 노드 편집(앵커 이동, 노드 추가/삭제, 핸들 편집) 또는 불리언 연산을 수행하면 `m_kind`를 `ShapeKind::Path`로 전환하고 `m_params`를 비웁니다. 이후 옵션바는 `선택 모드`로 표시됩니다.
- 전환 전에 사용자에게 알리지는 않지만 상태바에 "일반 패스로 변환됨"을 표시하고, Undo 시 파라미터 상태가 함께 복원되어야 합니다.
- 박스 스케일/이동/회전 같은 변환은 파라메트릭 상태를 유지합니다.

### 2.4 기하 재생성 함수

```cpp
void RebuildGeometry(PathShape&, const ShapeParams&, float w, float h);   // SubPath 재생성
```

`BoxShapeTool::UpdateGeometry`(현재 [ITool.cpp](../ITool.cpp)에 존재)는 이 함수를 호출하도록 리팩터링하여 생성 시 프리뷰와 수정 시 재생성이 **동일한 코드 경로**를 사용하게 합니다.

## 3. 사이드 툴박스 그룹핑 및 플라이아웃

### 3.1 그룹 구성

1. **사각형 그룹 (기본 대표: 사각형)**: 사각형, 삼각형
2. **정다각형 & 특수 도형 그룹 (기본 대표: 정다각형)**: 정다각형, 별, 기어, 스파이럴, 하트

> 용어 정리: **정다각형(Regular Polygon)** 은 변 수 N 파라미터로 만드는 도형입니다. 점을 클릭해 이어 그리는 **자유 다각형(Free Polygon)** 은 별개 도구이며 본 문서 범위가 아닙니다.

### 3.2 인터랙션 규칙

| 상황 | 동작 |
| :--- | :--- |
| 버튼 짧은 클릭 (< 300 ms, 이동 없음) | 현재 대표 도구 활성화 |
| 버튼 누른 채 300 ms 이상 유지 또는 우하단 삼각 영역 클릭 | 플라이아웃 펼침 |
| 펼친 상태에서 서브도구 위에서 MouseUp | 해당 도구 활성화, 대표 아이콘 갱신 |
| 서브도구 밖에서 MouseUp / `Esc` / 포커스 상실 | 취소 (기존 도구 유지) |
| 구현 전(Planned) 도구 | 비활성(회색) 표시, 선택 불가 |

- 대표 도구는 앱 설정(레지스트리)에 저장하여 재실행 시 유지합니다.
- 구현 방식: 툴박스 창이 **`SetCapture`를 유지**한 채 좌표 판정으로 서브 버튼을 하이라이트합니다. 플라이아웃은 `WS_EX_NOACTIVATE` 팝업으로 그리기만 담당합니다. (포커스 이동으로 인한 조기 닫힘 방지)

## 4. 도형별 상단 옵션바 컨트롤 명세

공통: 위치 필드 + `[W][H]` + `[회전°]`. 길이 필드는 활성 단위 사용. 링크 토글은 아이콘 리소스로 구현합니다.

| 도구 / 도형 | 레이블 | 컨트롤 | 비고 |
| :--- | :--- | :--- | :--- |
| **선택** | `선택 모드` | `X` `Y` `W` `H` `비율 링크 토글` `회전` | 다중 선택은 AABB 값 표시. 종류가 섞이면 파라미터 컨트롤 숨김 |
| **사각형** | `사각형 만들기/수정` | `X` `Y` `W` `H` `Rx` `Ry` `Rx=Ry 링크` `모서리 리셋` | 반경 상한 = 변 길이/2로 Clamp |
| **삼각형** | `삼각형 만들기/수정` | `X` `Y` `W` `H` `정삼각형 체크` | 체크 시 `H = W·√3/2` 구속 (4.1) |
| **타원** | `타원 만들기/수정` | `Cx` `Cy` `Rx` `Ry` `Rx=Ry 링크` | 링크 시 정원 |
| **정다각형** | `다각형 만들기/수정` | `Cx` `Cy` `반경 R` `변 수 N(3~32)` `회전` | |
| **별** | `별 만들기/수정` | `Cx` `Cy` `외경 R1` `꼭짓점 수 N(3~32)` `내경 비율 %(5~95)` | **내경 비율이 기준값.** R2 = R1×비율로 표시만 하고(읽기 전용), 직접 입력 불가 |
| **기어** | `기어 만들기/수정` | `Cx` `Cy` `외경 R` `톱니 수(6~48)` `톱니 깊이 %` `축 구멍 %` | 구멍은 외경 대비 비율 |
| **스파이럴** | `스파이럴 만들기/수정` | `Cx` `Cy` `외경 W,H` `회전 수(0.5~10)` `내경 %` | 아르키메데스 나선 |
| **하트** | `하트 만들기/수정` | `X` `Y` `W` `H` | 파라미터 없음 |

### 4.1 입력 검증 규칙

- W, H, R 등 길이: 최소 `0.01 px` 이상. 0 이하 입력은 직전 유효값으로 복원하고 필드를 빨간색으로 잠시 표시합니다.
- 정수 파라미터(N, 톱니 수)는 범위로 Clamp하고 소수는 반올림합니다.
- 비율 파라미터는 범위를 벗어나면 Clamp합니다.
- NaN/Infinity/지나치게 큰 값(예: 1e7 px 초과)은 거부합니다.
- 음수 W/H로 인한 **뒤집기(flip)** 는 허용하지 않고 입력 시 거부합니다. (뒤집기는 별도 변환 명령)
- 키보드: `Tab` 이동, `Enter` 확정, `Esc` 취소, `↑/↓` 증감(Shift = ×10, Alt = ×0.1).

## 5. 엔진 기하학 수식 모델

모든 도형은 `RebuildGeometry`에서 로컬 박스 `[0,0,W,H]` 기준 `SubPath/BezierNode`로 생성합니다. 원형 계열은 박스에 내접하며 반경은 `Rx = W/2`, `Ry = H/2`, 중심 `(W/2, H/2)`로 정의합니다(타원 변형 허용).

### 5.1 삼각형
- 정점: `P0(W/2, 0)`, `P1(W, H)`, `P2(0, H)`. 닫힌 패스, 모두 Corner 노드.
- 정삼각형 모드: `H = W·√3/2`.

### 5.2 정다각형 / 별
- 중심 `(cx, cy)`, 반경 `Rx, Ry`, 변 수 `N`.
- 정다각형 정점: `θ_i = rot + 2π·i/N`, `P_i = (cx + Rx·sin θ_i, cy − Ry·cos θ_i)`.
- 별: 정점 `2N`개, `dθ = π/N`.
  - 외경 점: `θ = rot + 2i·dθ`, 반경 `(Rx, Ry)`
  - 내경 점: `θ = rot + (2i+1)·dθ`, 반경 `(Rx·k, Ry·k)`, `k = innerRatio`
- 모두 닫힌 패스, Corner 노드.

### 5.3 기어
- 톱니 수 `T`, 외반경 `Ro`, 톱니 깊이 `d = depthRatio·Ro` → 루트 반경 `Rr = Ro − d`, 축 구멍 반경 `Rb = boreRatio·Ro` (`Rb < Rr` 조건 Clamp).
- 한 톱니 각도 피치 `α = 2π/T`. 톱니 폭 비율 `w = toothWidthRatio`(기본 0.5) 로 한 피치를 다음 4구간으로 나눕니다.
  - 루트 호 (`Rr`) → 상승 플랭크 → 팁 호 (`Ro`) → 하강 플랭크
  - 팁 각폭 `α·w·0.5`, 루트 각폭 `α·(1−w)·0.5`, 나머지는 플랭크 각폭이며 플랭크는 직선(선분)으로 근사.
- 외곽은 1개 닫힌 SubPath, 축 구멍은 **반대 방향** 원 SubPath(4-노드 베지어 원, `κ = 0.5523`).
- **전제 조건**: 구멍을 뚫으려면 Fill Rule(EvenOdd 또는 NonZero+방향 반전)이 `SubPath/PathShape`에 지원되어야 합니다. 지원 전에는 외곽 방향과 구멍 방향을 반대로 만들고 기본 NonZero를 사용합니다. (아키텍처 문서 9.1 Fill Rule 항목과 연동)
- 톱니 수가 많을 때 정점 수 = `4T + 4` 이내가 되도록 상한(48)을 둡니다.

### 5.4 스파이럴 (아르키메데스 나선)
- `r(θ) = r0 + b·θ`, `θ ∈ [0, 2π·turns]`
  - 외반경 `R = r0 + b·2π·turns` (박스에서 결정), 내반경 `r0 = innerRatio·R`
  - `b = (R − r0) / (2π·turns)`
- 열린 패스. 기본 제어점은 세그먼트당 **최대 π/4(45°)** 간격으로 샘플링하고 각 구간을 3차 베지어로 근사합니다.
  - 구간 `[θa, θb]`의 앵커 `P(θ)`, 접선 `P'(θ) = (r'·cosφ − r·sinφ, r'·sinφ + r·cosφ)` 를 사용하여 Hermite→Bezier 변환: `C1 = P(θa) + P'(θa)·(θb−θa)/3`, `C2 = P(θb) − P'(θb)·(θb−θa)/3`.
- 노드 수 상한: `turns × 8 + 1` (10회전 기준 81개).
- 로그 나선이 필요하면 별도 `Mode` 파라미터로 확장합니다(본 단계 범위 외).

### 5.5 하트
- 로컬 박스 `[0,0,W,H]`, 닫힌 패스, 노드 4개. 핸들은 박스 대비 비율로 고정:

| 노드 | 앵커 | 종류 | hIn | hOut |
| :--- | :--- | :--- | :--- | :--- |
| 하단 뾰족점 | `(0.5W, H)` | Corner | `(+0.28W, −0.20H)` 오른쪽 위 방향 | `(−0.28W, −0.20H)` 왼쪽 위 방향 |
| 좌측 볼록점 | `(0, 0.33H)` | Smooth | `(0, +0.30H)` | `(0, −0.30H)` |
| 상단 중앙 골 | `(0.5W, 0.22H)` | Corner | `(−0.22W, −0.22H)` | `(+0.22W, −0.22H)` |
| 우측 볼록점 | `(W, 0.33H)` | Smooth | `(0, −0.30H)` | `(0, +0.30H)` |

> 위 비율은 초기값이며, 구현 후 렌더링 결과를 보고 미세 조정합니다. 노드 순서는 하단 → 우측 → 상단 골 → 좌측 시계/반시계 방향 일관성을 유지해야 하며, 방향이 반대인 경우 hIn/hOut을 맞교환합니다. (핸들 오프셋 표기는 `BezierNode` 정의의 로컬 오프셋 기준)

## 6. UI 프레임워크 설계 및 알려진 이슈 (MFC)

1. **상단 옵션바 컨테이너 선택**
   - 1안: `CDockablePane` 상단 고정 도킹. 고정 높이(36~40px)를 위해 `CPane::CalcFixedLayout` 계열 처리가 필요합니다.
   - 2안: 메인 프레임 상단에 `CDialogBar`/`CMFCToolBar` 계열 컨트롤 바 배치. 고정 높이 요구에는 더 단순합니다.
   - 우선 검증 후 확정하고, 선택 이유를 본 문서에 기록합니다.
2. **알려진 이슈: 도킹 ASSERT**
   - `CDockablePane` 상단 도킹 시 `IsResizable()`을 `FALSE`로 무조건 반환하면 도킹 매니저 내부에서 `ASSERT`가 발생한 사례가 있습니다. (구체적인 ASSERT 위치와 재현 조건은 구현 시 기록)
   - 이전 도킹 상태가 레지스트리에 높이 0으로 저장되어 깨질 수 있으므로, 생성 직후 `ShowPane(TRUE, FALSE, TRUE)` 호출과 유효한 캡션 문자열 지정이 필요합니다. 필요 시 상태 키 초기화 옵션을 제공합니다.
3. **플라이아웃 포커스**
   - 일반 `WS_POPUP`을 띄우면 `WM_KILLFOCUS`가 클릭보다 먼저 와서 서브메뉴가 닫힐 수 있습니다. 3.2의 `SetCapture` + `WS_EX_NOACTIVATE` 방식을 사용합니다.
4. **DPI**: 옵션바 컨트롤 크기와 폰트는 DPI 스케일을 따릅니다.

## 7. 구현 단계

| 단계 | 내용 | 완료 조건 |
| :--- | :--- | :--- |
| **P1** | 옵션바 컨테이너 + 선택 모드(X/Y/W/H/회전) + 단위 연동 + 우측 패널 동기화 | 값 편집이 Undo 1회로 복원, 단위 전환 시 내부 값 불변 |
| **P2** | `ShapeKind/ShapeParams` 모델 + `RebuildGeometry` 리팩터링 (사각형, 타원 이관) | 기존 사각형/타원의 생성/수정/저장 동작 유지 |
| **P3** | 삼각형, 별, 정다각형, 하트 추가 + 해당 옵션바 | 수정 모드 파라미터 변경 시 실시간 반영 |
| **P4** | 플라이아웃 서브도구 (사각형 그룹, 다각형 그룹) | 3.2 규칙 전체 통과 |
| **P5** | Fill Rule 지원 후 기어, 스파이럴 추가 | 구멍 렌더링, 노드 수 상한 준수 |
| **P6** | 다중 선택 혼합값 표시, 키보드 증감, 접근성 | 아키텍처 문서 9.3 요구와 정합 |

> P5는 Fill Rule 모델 보강에 의존합니다. 의존이 해소되지 않으면 기어 보어 구멍 없이 먼저 출시할 수 있습니다.

### 5.6 도형 작성 기준점 모드 (From Center / From Corner)
- **개요**: 사각형, 타원, 삼각형, 정다각형, 별, 기어, 나선, 하트 등 완성도형 생성 시 기본 모서리 시작(From Corner, 좌상단->우하단 등) 외에 중심 시작(From Center, 중심->바깥쪽 대칭 확장) 옵션을 상단 도구 옵션바(ToolOptionBar)에서 토글 지원.
- **UI 토글 버튼**: `ID_OPT_DRAW_CENTER`
  - `[From Center✓]`: 첫 클릭 지점을 도형의 중심(Center)으로 삼고 양방향 대칭으로 크기를 확장.
  - `[From Corner]`: 첫 클릭 지점을 도형의 한 모서리(Corner)로 삼고 마우스 위치까지 확장.
- **단축키/모디파이어 연동**: 드래그 중 `Alt` 키를 누르면 옵션바 설정과 무관하게 즉시 From Center 모드로 작동.
- **중심 앵커 시각화**: From Center 모드로 드래그 중 첫 번째 클릭점(중심점)에 오렌지색 십자선 가이드 렌더링.

## 8. 테스트 항목

- 도형별 정점/노드 수 검증 (삼각형 3, 별 2N, 기어 4T, 하트 4 등)
- 파라미터 변경 후 로컬 바운딩 박스가 `[0,0,W,H]`와 일치하는지
- From Center / From Corner 옵션 토글 및 Alt 키를 통한 대칭 확장 동작 검증
- 정삼각형 구속 `H = W·√3/2`
- 스파이럴 근사 오차 (샘플 지점과 실제 `r(θ)` 편차 < 허용치)
- 기어 `Rb < Rr < Ro` 제약과 구멍 방향
- Undo/Redo: 입력 1회 = 명령 1회, `Esc` 취소 시 명령 없음
- 노드 편집 후 `ShapeKind::Path` 전환 및 Undo 시 파라미터 복원
- 단위 전환(px→mm→px) 왕복 시 값 드리프트 없음
- 회전된 도형과 다중 선택의 AABB 편집 기준점
- 옵션바 ↔ 우측 패널 동기화 시 무한 갱신 없음
- 플라이아웃: 짧은 클릭, 길게 누르기, 밖에서 놓기, `Esc`, 포커스 상실
- 입력 검증: 0, 음수, NaN, 매우 큰 값, 정수 파라미터에 소수 입력
- 저장 후 재로드 시 `ShapeKind`와 `ShapeParams` 유지
